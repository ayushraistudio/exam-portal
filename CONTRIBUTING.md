# Contributing to ExamPorta

Thank you for considering contributing to **ExamPorta**!  
Your contributions help make this project better, more secure, and more scalable 🚀

---

## 🧭 How to Contribute

### 1. Fork the Repository
Fork the repository using the Fork button on GitHub.

### 2. Clone Your Fork
```bash
git clone https://github.com/your-username/exam-portal.git
cd exam-portal
```
### 3. Install Dependencies
```bash
npm install
```
### 4. Create a New Branch
```bash
git checkout -b feature/your-feature-name
```

## 🛠️ What You Can Work On

You can contribute in the following areas:

- 🐞 Bug fixes
- ✨ New features (Admin / Student modules)
- 🎨 UI & UX improvements
- 📄 Documentation improvements
- ⚡ Performance optimizations
- 🔐 Security enhancements

For large changes, please open an Issue before starting work.

## 📐 Code Guidelines

- Use functional components with React Hooks  
- Keep components modular and reusable  
- Follow the existing folder structure  
- Use Tailwind CSS utility classes  
- Do NOT commit Firebase keys or secrets  
- Test changes locally before pushing  

---

## ✅ Commit Message Format

Use clear and meaningful commit messages:

feat: add admin leaderboard  
fix: resolve exam timer auto-submit bug  
docs: update README  

---

## 🔁 Submitting a Pull Request

1. Push your branch:
git push origin feature/your-feature-name

2. Open a Pull Request on GitHub  
3. Clearly describe what you changed and why  
4. Link the related Issue (if any)

---

## 🧪 Testing

- Ensure the app runs without errors  
- Test both Admin and Student flows  
- Verify mobile responsiveness if UI is modified  

---

## 📜 Code of Conduct

Be respectful and professional.  
Harassment, abuse, or inappropriate behavior will not be tolerated.

---

Thank you for contributing to **ExamPorta** 💙  
Happy coding!
